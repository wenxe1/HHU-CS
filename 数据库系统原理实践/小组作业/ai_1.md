# 数据库课程实践大作业统一参考指南

## 1. 项目背景与需求概述

**项目名称**：校园一卡通消费系统
**核心对象**：学生/教职工（用户）、校园一卡通卡片、消费商户、消费记录、充值记录。
**核心业务逻辑**：

- 
- **用户与卡**：1个用户对应1张主卡（唯一卡号）；卡片状态包括正常、挂失、注销。
- **消费**：用户在指定商户消费，需记录流水。
- **充值**：支持线下/线上充值。
- **余额规则**：余额 = 累计充值 - 累计消费，且**余额不可为负数**。

## 2. 环境与工具准备

根据《安装部署手册》与《金融场景化实验》，实验环境配置如下：

### 2.1 软硬件配置

- 
- **操作系统**：openEuler 20.3 LTS (ARM架构，华为云ECS)
- **数据库版本**：openGauss 5.0.1
- **开发语言**：Java (需安装JDK)
- **连接工具**：gsql (命令行)、Data Studio (图形化，可选)、PuTTY/Xshell (远程SSH)

### 2.2 数据库连接配置 (关键参数)

- 
- **数据库端口**：26000 (默认)
- **超级用户**：omm (操作系统用户及数据库管理员)
- **配置修改** (用于支持远程 JDBC 连接，参考《金融场景化实验》1.2.1):
  1. 
  2. **pg_hba.conf**: 添加 host all all 0.0.0.0/0 sha256 以允许外部连接。
  3. **postgresql.conf**: 设置 listen_addresses = '*'。
  4. **重启生效**: gs_om -t restart。
  5. **安全组**：华为云控制台需放通入方向 26000 端口。

## 6. 常用参考命令速查 (基于附录)

- 
- **启动/停止数据库** (omm用户):
  - 
  - gs_om -t start
  - gs_om -t stop
- **连接数据库** (omm用户):
  - 
  - gsql -d postgres -p 26000 -r
- **常用元命令**:
  - 
  - \l : 列出所有数据库
  - \c dbname : 切换数据库
  - \d : 列出当前数据库下的表
  - \d tablename : 查看表结构
  - \q : 退出
- **SQL 基础**:
  - 
  - 创建模式: CREATE SCHEMA schema_name;
  - 创建用户: CREATE USER user_name IDENTIFIED BY 'password';
  - 授权: GRANT SELECT ON table_name TO user_name;
