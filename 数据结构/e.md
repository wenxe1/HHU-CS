绪论
1数据类型：计算机语言可以使用的一个类型，包括这个类型的值的集合，以及定义在该类型上的一组操作
抽象数据类型：具有一定行为和操作的数据类型，是逻辑层面的定义
抽象数据类型和数据结构的关系：数据结构是抽象数据类型通过编程语言的物理实现

2数据结构分类
    按逻辑结构分类：集合(一群羊)，线性结构(一对一/排队)，树形结构(可以一对多/思维导图)，图形结构(可以多对多/道路)
        线性结构：线性表、字符串、栈、队列
        非线性结构：树，图
    按存储（物理）结构分类：
        顺序存储（逻辑相邻<=>物理相邻）
        非顺序存储：链式，散列，索引（逻辑相邻!=物理相邻）

(1)集合结构：结构中的数据元素之间除“同属一个集合”外，别无其它关系（一群羊）
(2)线性结构：结构中的数据元素之间只存在一对一的关系，除了第一个和最后一个元素，所有元素都有唯一前驱和后继（排队取号）
(3)树形结构：结构中数据元素之间存在一对多的关系（思维导图）
(4)图状结构：数据元素之间是多对多的关系（道路信息）

(1)集合：不存在前驱、后继的关系
(2)线性结构：唯一前驱，唯一后继
(3)树型结构：唯一前驱，后继可以不唯一？
(4)图结构：前驱、后继均可不唯一？

逻辑结构和存储结构的关系，并列举实际场景加以说明
逻辑结构：模型中的基本元素，及其之间的相互关系，是抽象的关系，与计算机实现无关
存储结构：模型（元素，关系）在计算机内存中的物理存储方式，具体实现逻辑结构
关系：（1）逻辑结构决定存储结构的设计目标
（2）存储结构影响逻辑结构的性能
（3）相互独立，同一逻辑结构可通过不同存储结构实现，同一存储结构也可以支持多种逻辑结构

实例：学生名单管理
逻辑结构：线性表（按学号顺序排列）
存储结构：（1）数组：学号连续存储，可快速查找，但插入新学生需移动大量数据。
（2）链表：学号分散存储，插入新学生只需修改指针，但查找学生需从头遍历

3算法：由有穷规则构成、为解决某一问题而规定的运算序列
性质：有若干输入和输出（有零个或多个输入，有一个或多个输出）
    有穷性：执行有穷步结束
    确定性：每一步都有确切的定义
    可行性：可由机器或者人准确完成
问题规模：待处理数据的规模
算法性能分析：算法执行所需时间和内存空间，即算法的时间复杂度（问题规模n的函数）和空间复杂度（算法除本身所需存储外的辅助空间）

4时空复杂度计算
二叉树顺序表示：寻找孩子兄弟父亲复杂度O(1);适用于完全、“接近完全”的二叉树（否则未用空间过多

顺序检索成功失败的ASL->O(n)
有序字典二分检索成功失败的ASL->O(log2n)，插入删除O(n)

邻接表（边数e：空间复杂度O(n+e)，统计边O(n+e)，判断邻接O(n)，有向图（出边表）计算入度O(n+e)
bfs：邻接表 -> O(n+e)  邻接矩阵 -> O(n^2)

    vexset，判断顶点s、t是否连通：O(1)

最短路径
（3）Dijkstra(权重非负)：O(n^2)
拓扑排序：O(n+e)（出边表
直接插入：比较O(n2)，元素移动O(n2)

线性表
1定义：有限个、类型相同的元素组成的有序序列
性质：同一性：所有元素类型相同
    有序性：(首, 尾除外) 唯一前驱和唯一后继
    有穷性：元素(结点)个数有限

2存储
顺序存储：
    用一组连续的内存单元,按照逻辑顺序依次存储线性表中的元素
    ->顺序表

链式存储：
    用一组非连续的内存单元，分别存储
    用指针指示元素之间的逻辑关系和存储地址 
    ->链表

3优缺点分析
顺序表
    优点：
        1.存储密度高
        2.支持随机存取
    缺点：
        1.不方便插入或删除，需依次移动大量元素
        2.预先分配的存储空间，可能溢出，也可能长期闲置
单链表
    优点：
        1.方便插入或删除，只需修改指针，无需移动元素
        2.动态分配存储空间
    缺点：
        1.存储密度比顺序表低
        2.不能随机访问第i个元素，需顺链查找

二叉树
1基本概念
(1)结点的度：一个结点的分枝个数
(2)结点层数(0起)
(3)二叉树的深度(高度)：结点的最大层数
(4)父亲结点：存在分枝的结点
子结点(儿子结点)：由分枝而产生的结点
父结点是子结点的前驱，子结点是父结点的后继
子结点分为：左孩子、右孩子

2特点
每个结点是其左、右子树中根结点的前驱
后继：结点的左、右孩子
除树根结点外，所有结点只有1个前驱
任何结点的后继≤ 2个

3性质
(1)层数从0开始，第i层最多有2^i个结点
结点的度最大为2 -> 每层结点数最多是上一层的2倍
(国内)满二叉树每一层都达到最大结点数
(2)高度为k的二叉树，最多有2^(k+1)-1个结点(k>=0)，最少有k+1个结点
(3)非空二叉树，叶子结点(度为0)n0个，度为1的结点n1个，度为2的结点n2个，则：
结点总数：n = n0 + n1 + n2
唯一父亲,根节点没有父亲 -> 边的总数：B = n-1
0~2个孩子 -> 边的总数：B = 0*n0+ 1*n1+ 2*n2
n0 = n2 + 1
(4)n个结点的二叉树(二叉链表)，有n+1个空指针(2n个指针，n-1个父亲指针)


4特殊二叉树
满二叉树
定义1(美国/国际/教材)(2树)：任意结点度为0或2，即结点或是叶子或有两棵非空子树

定义2(国内)：除叶子外，其他结点都有2个孩子，且叶子结点都在最后一层
            即除最后一层无子结点外，每层上的任意结点都有两个子结点
性质：叶结点比分枝结点多1个
B =  n0 + n2 - 1 = 2*n2


5完全二叉树
定义：(1)只允许最后两层结点的度数小于2，最后一层结点都集中在该层最左边的若干位置
基本概念：(1)(国内)满二叉树必为完全二叉树
(2)设结点的编号规则：层间从上到下，层内从左到右 -> 完全二叉树、满二叉树的结点序号一一对应
(3)在满二叉树(国内)的最后一层，从最右结点开始向左连续删除若干结点后，得到一棵完全二叉树

性质：
(1)有n个结点的完全二叉树，其高度k为log2n(下取整)
(2)高度为k的满二叉树，结点数：A = 2^(k+1)-1
-> 高度为k的完全二叉树结点数，2^(k)-1 < n ≤ 2^(k+1)-1
(3)有n ≥1个结点的二叉树，其高度最大值(结点最大度为1)n-1，最小值(完全二叉树)log2n(下取整)
(4)n个结点的完全二叉树, 按照”层间从上到下，层内从左到右”，对其结点从0到n-1进行编号(二叉树顺序表示)
当i > 0，结点i的父结点为 (i-1)/2(下取整)
当2i+1 ≤ n-1，结点i的左孩子为2i+1
当2i+2 ≤ n-1，结点i的右孩子为2i+2
当i为偶数且≠ 0，其左兄弟为i-1
当i为奇数且i+1 ≤ n-1，其右兄弟为i+1

6扩充二叉树
(1)扩充：将二叉树的所有结点扩充成度为2的分枝结点(包括度为0的结点)
(2)非空二叉树，扩充后，成为2树(国际)
(3)内部结点：原有结点  
内部路径长度I：从根到每个内部结点的路径长度之和
外部结点：新增结点
外部路径长度E：从根到每个外部结点的路径长度之和
在扩充二叉树中，所有叶子都是外部结点

7平衡二叉树
(1)结点的平衡因子：该结点的左、右子树深度之差
(2)平衡二叉树：所有结点平衡因子的绝对值都不大于1
(3)(国内)满二叉树：所有结点的平衡因子都等于0
(4)完全二叉树是平衡的

8二叉树的先序中序后序遍历(深度优先遍历)
给定二叉树，则先根、中根、后根序列唯一
给定一个中根序列，和一个先根或后根序列，则唯一确定一棵二叉树

线索二叉树
1思想：改造空指针为线索，保存某种遍历过程中的前驱、后继关系，提高遍历速度
空的llink存储结点在某遍历序列中的前驱；
空的rlink存储结点在某遍历序列中的后继

2基本概念
(1)线索化：在遍历二叉树的过程中，重置空指针
(2)线索：是指针，指向结点在某个遍历序列中的前驱或后继

3中序线索化
遍历过程中，线索化：访问结点p后，看p->llink、p的前驱的rlink是否为空？若是，则重置空指针。

哈夫曼树
1定义：将m个带权结点作为叶子，构造二叉树，其中带权路径长度最小的为哈夫曼树
叶子的带权路径长度：权值×路长：wi × Li；
树的带权路径长度(WPL)：叶子带权路长之和 i(wi × Li)

2特点：权值越大，离根越近
带权结点是叶子(外部结点)

3性质
(1)哈夫曼树一定是2树
(2)哈夫曼树结点总数2*m-1 = m + 0 + (m - 1)

图
1基本概念
图状结构：可以多对多
组成：顶点集合V，以及定义在该集合上的关系集合E
符号：G = (V, E)
无向图：1条边上的2个顶点组成无序对  (A, D) <=> (D, A)
有向图：1条边(弧) 上的2个顶点组成有序对  <C, D> 起点C, 终点D
简单图：（1）无环
        （2）顶点之间无重边
完全图G：任意两个顶点之间，都有1条边（顶点数n，边数e）
        G为有向图，e = n(n - 1)
        G为无向图，e = n(n - 1) / 2
度：
    无向图：V的度：V的关联边的个数
    有向图：V的入度：以V为终点的边数；
            V的出度：以V为起点的边数；
            V的度：入度 + 出度
    -> 边数e = 1/2 * ∑di

2 图的表示（存储）
（1）邻接矩阵
    优点：判断邻接O(1)
        有向图中计算任一顶点的度O(n)
    缺点：空间复杂度O(n^2)
        统计边，时间复杂度O(n^2)
（2）邻接表
    优点：空间复杂度O(n+e)
        统计边，时间复杂度O(n+e)
    缺点：判断邻接，最坏情况：长为n的单链表，O(n)
        有向图（出边表），计算入度，复杂度O(n+e)
